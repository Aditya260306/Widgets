0.  How to Use This Document
This brief is designed to be fed verbatim into two AI design tools: Google Stitch and Figma Make. Each section is structured to give the AI exactly what it needs to generate high-fidelity, accurate screens. Read this section before using either tool.

0.1  Workflow Overview
Read this entire document once before starting either tool.
Open Google Stitch. Start a new project. Paste the design system section (Section 1) as the base context, then feed each screen section (2–8) one at a time.
Open Figma Make. Create a new Figma file. Use the design system section to generate your component library first, then generate each screen.
For each screen, generate with both tools.
Screenshot or export both versions side-by-side.
Evaluate using the comparison rubric in Section 9 of this document.
Pick the winner per screen, note your decision, and proceed to implementation.

0.2  How to Prompt Each Tool





1.  Design System

1.1  Design Philosophy — Paste This Verbatim
AURA is a personal Android app that manages AI-powered home screen widgets. The design language is "Quiet Luxury" — the visual equivalent of a well-made, unbranded object. Nothing competes for attention. Everything earns its place. The primary inspiration is Niagara Launcher: extreme restraint, generous whitespace, one typeface, no bottom navigation bar, and gesture-first navigation. Secondary inspirations: Linear.app (for its dark dense UI with surgical typography), Craft (for its satisfying interaction model), Blackbox app (for rewarding exploration with hidden interactions).

Every design decision should pass this test: "Would a user notice this if it was removed?" If yes, keep it. If no, remove it.

1.2  Colour Palette
These are the ONLY colours used in the entire application. Do not introduce any other colours.

Primary Backgrounds

Background Base (#0A0A0F): Main screen background. Near-black, almost no blue tint. Not pure black — has warmth.
Background Surface (#0F0F1A): Widget cards, list items, anything that sits on top of the base.
Background Elevated (#1A1A2E): Bottom sheets, modals, dialogs. Clearly above the surface.
Background Highest (#2D2D3A): Tooltips, popovers — the highest floating elements.

Accent Colours

Violet (#7C5CFC): Primary interactive colour. AI features, primary buttons, selected states, active navigation indicators, borders on focused inputs. Used most frequently among accents.
Mint (#00D4A8): Success states, completed habits, live/real-time data indicators, charging battery, positive trends. Never used for primary actions.
Rose (#FF5F87): Errors, destructive actions, alerts, warnings. Used sparingly — when it appears, it means something important.
Gold (#F4C542): Reserved exclusively for the AI Insight widget content — the highest-value AI-generated content. Extremely rare. When users see gold, they know it is special.

Ghost / Tinted Backgrounds

These are used as tinted background fills for callout boxes, info panels, and notification banners in the light context only. On dark backgrounds, use the accent colour at 10% opacity instead.

Text Colours

Text Primary (#F0F2F7): All main readable text on dark backgrounds. Slightly warm white — not pure white, which feels harsh.
Text Secondary (#6B7A99): Timestamps, labels, secondary descriptions, hints, placeholder text.
Text Tertiary (#B8C2D4): Disabled states, captions, legal text. The quietest voice.
Text on Accent (#FFFFFF): Text rendered on any coloured button or accent background.

1.5  Elevation System
AURA does not use drop shadows. Elevation is communicated through background colour only. The darker the background relative to the element on top, the higher it appears.

Failure Mode | How to Spot It | Fix in Next Prompt
Wrong background colour | The background looks dark grey or #1C1C1E (iOS dark grey) instead of our very specific #0A0A0F | Add: "Background MUST be exactly #0A0A0F — not #1C1C1E, not #121212. This exact hex."
Bottom navigation bar added | A standard bottom nav bar with 3–4 icons appears at the bottom | Add: "DO NOT add a bottom navigation bar. AURA has no bottom nav. Navigation is gesture-based."
Wrong fonts used | Inter, Roboto, or San Francisco used instead of Georgia + Noto Serif | Add: "Use ONLY Georgia for headings and Noto Serif for body. No sans-serif fonts anywhere."
Rounded rect abuse | Everything has the same 12dp radius including things that should have more (bottom sheets = 28dp) or less | Specify radii explicitly for each component in the prompt.
Purple gradient backgrounds | The AI adds a purple-to-dark gradient behind everything — a very common AI design cliché | Add: "NO gradients on background. Solid #0A0A0F ONLY. Gradients only on the fidget space orbs."
Too many elements | The AI adds labels, explanations, help text, and secondary info that was not specified | Add: "Include ONLY the elements listed. Do not add any unspecified text, icons, or UI elements."
Light theme default | The AI generates a light theme despite clear dark theme specification | Add: "This is a DARK THEME APP. Background is near-black. All text is light. There is no light mode for this screen."
